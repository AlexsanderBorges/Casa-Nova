# Casa Nova — Alex, Jessica & Ayla

Site de lista de presentes com 100 itens, reservas e painel administrativo.

## Firebase conectado
Projeto Firebase: `casa-nova-ad182`

## Próximo passo
No Firebase Console, em **Firestore Database → Regras**, publique o conteúdo de `firestore.rules` deste projeto.

Depois, no painel `/admin.html`, entre com o usuário criado em Firebase Authentication e clique em **Cadastrar / sincronizar os 100 presentes**.

O `index.html` é público; o `admin.html` exige autenticação.
